## Featured Project

### SlugShield — Privacy-Preserving Intrusion Detection System (IDS)  
**Python, FastAPI, React, Networking, Security**

A lightweight, offline-first intrusion detection system designed to monitor **local IoT and smart-device network traffic** while preserving user privacy.

**Key highlights:**
- Offline-first architecture with **local-only inference** (no cloud dependency)
- **Heuristic-based anomaly detection** for suspicious ports, packet patterns, and abnormal traffic bursts
- **Privacy-preserving logging and alerting** using hashed records and encrypted summaries (no raw packet storage)
- **Real-time monitoring dashboard** built with FastAPI and React
- **Config-driven detection thresholds** (YAML) for flexible tuning across environments
- **Traffic simulation tools** to validate detections against port scans, flooding, and spoofing scenarios
- Configurable **email alerting** for threshold-based attack notifications

> See the SlugShield directory for detailed design docs, backend/frontend architecture, and demo scripts.
