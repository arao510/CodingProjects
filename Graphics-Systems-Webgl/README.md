# WebGL to Three.js Graphics Systems

This repository contains a series of projects built throughout a computer graphics course, progressing from foundational linear algebra and 2D rendering to full 3D environments, lighting systems, and interactive applications using WebGL and Three.js.

## 🚀 Live Projects

### Assignment 0 – Vector Visualizer
🔗 https://arao510.github.io/CSE160/CSE160/ASG0/asg0.html  
Built an interactive vector visualization tool to perform operations like addition, normalization, dot product, and cross product.  
**Skills:** Linear algebra, vector math, canvas rendering, JavaScript fundamentals

---

### Assignment 1 – Interactive Drawing App
🔗 https://arao510.github.io/CSE160/ASG1/  
Developed a browser-based drawing application supporting multiple shapes, colors, and user-controlled rendering.  
**Skills:** WebGL basics, event handling, UI controls (sliders/buttons), object-oriented design

---

### Assignment 2 – 3D Animation Engine
🔗 https://arao510.github.io/CSE160/ASG2/index.html  
Created a hierarchical 3D model with joint-based animation and transformation matrices for real-time rendering.  
**Skills:** 3D transformations, matrix operations, hierarchical modeling, animation systems

---

### Assignment 3 – Voxel World Engine
🔗 https://arao510.github.io/CSE160/ASG3/index.html  
Built a first-person 3D voxel world with camera controls, procedural map generation, and real-time navigation.  
**Skills:** Camera systems, perspective projection, world generation, keyboard/mouse interaction

---

### Assignment 4 – Lighting & Shading Engine
🔗 https://arao510.github.io/CSE160/ASG4/index.html  
Implemented a Phong shading pipeline with dynamic lighting, normals, and shader-based rendering.  
**Skills:** GLSL shaders, lighting models (ambient/diffuse/specular), normals, rendering pipelines

---

### Assignment 5 – Three.js 3D World Explorer
🔗 https://arao510.github.io/CSE160/ASG5/index.html  
Rebuilt a 3D interactive environment using Three.js with textured models, multiple light sources, and camera controls.  
**Skills:** Three.js, high-level 3D frameworks, scene composition, model loading, lighting systems

---

## 🧠 Key Skills Developed

- **Computer Graphics:** WebGL, Three.js, rendering pipelines  
- **Mathematics for Graphics:** Linear algebra, vectors, matrices, transformations  
- **3D Systems:** Camera movement, projection, hierarchical modeling  
- **Shaders & Lighting:** GLSL, Phong shading, normals, lighting models  
- **Interactive Systems:** Event handling, real-time rendering, user input  
- **Software Engineering:** Object-oriented design, debugging, working with large codebases  

---

## 📌 Summary

This progression reflects building a complete graphics pipeline—from low-level rendering and math foundations to high-level 3D applications using modern libraries.
